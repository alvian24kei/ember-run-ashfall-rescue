Ember Run: Ashfall Rescue — a volcano-rescue flight game at dusk: fly four sorties over an erupting archipelago, thread 12 golden rings, pick up 7 survivors at the glowing orange beacons, chain rings and rescues into a combo up to x5, grab fuel canisters, repair kits and shields, fight gust winds through the ashfall, and land at Meridian Field to see the full debrief.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Fly with arrow keys or WASD, W/S for throttle, mouse to steer, P to pause, M to mute.
